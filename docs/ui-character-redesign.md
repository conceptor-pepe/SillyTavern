## 聊天体验补充

## 接口与持久化

角色创建在原有字段之外新增：

| JSON 请求字段 | 类型 | 限制/保存方式 |
| --- | --- | --- |
| portrait | string | 可选 JPEG data URL；最多 350000 字符，宽高各不超过 1024；服务器重编码去除元数据 |
| tags | string[] | 最多 9 个；去首尾空白后非空且不重复；每个最多 24 字；保存于已有 tags JSON 列 |
| gender | string | 空、female、male、other |
| age | string | 最多 8 字；允许虚构角色年龄表示 |
| message_sample | string | 保存到已有 message_sample 列 |

portrait、gender、age 保存于现有 extra_data JSON。没有数据库结构变更。
查询兼容现有大写响应字段 Portrait、Tags、Gender、Age、MessageSample，由前端适配为小写。
整个创建请求限制 1 MiB；简介、性格、场景、开场白和示例对话各最多 60000 字节。
浏览器接收 5 MiB 以内 JPG/PNG/WebP，并先压缩到最长边 512 的 JPEG。没有将原始用户图片放进公开静态目录。
内置静态 JPEG 由已有 PNG 转换，不携带角色卡 PNG 文本块。
角色列表与详情仍按登录用户隔离。
